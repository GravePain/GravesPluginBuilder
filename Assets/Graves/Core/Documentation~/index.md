## In the editor

Everything here also renders inside Unity: **Graves → Authoring Window → Manual**, one click from
the thing you are authoring. That is the point of it — a document in a folder nobody has open is a
different document from one beside the work.

## If the Manual tab is empty

This folder did not travel. A `~` folder is invisible to Unity and easy to miss when a framework is
installed by copying rather than as a package. The tab will tell you exactly where it looked.
